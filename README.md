# Prompt Engineering Experiments

An Ironhack notebook exercise by David Gill comparing prompts for sentiment analysis, product descriptions and structured data extraction.

## Approach

The experiments compare initial prompts with more explicit constraints, structured-output requirements, few-shot examples and reasoning-oriented instructions. The learning summary discusses repeated groups of 5, 10 and 15 runs.

## Files

- [prompt_engineering_lab.ipynb](prompt_engineering_lab.ipynb): experiment prompts, code and recorded output.
- [lab_summary.md](lab_summary.md): findings, remaining formatting problems and hallucinated product claims.

## Review locally

Open the notebook in Jupyter or VS Code. Check its imports, installation cells and provider configuration before running it. Use your own credentials in the local environment, and review which cells make chargeable model calls.

## Findings and limits

The recorded observations favour explicit formats and examples for more consistent responses. Some unsupported product claims and inconsistent JSON remained. These are small development experiments, not a general benchmark of prompt effectiveness. No new model calls or statistical validation were performed for this README.
