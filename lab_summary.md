In this lab, I tested and improved prompts for sentiment analysis, product description generation, and structured data extraction using systematic prompt engineering techniques. Initial zero-shot prompts showed inconsistent formatting, unreliable structure, and hallucinated content, especially in product descriptions. By adding explicit constraints, structured output requirements, few-shot examples, and Chain-of-Thought reasoning, the prompts became significantly more consistent across repeated 5, 10, and 15-run tests. Few-shot prompting was the most effective technique for improving formatting and response consistency, while Chain-of-Thought prompting improved reasoning reliability for data extraction tasks. Some hallucinated product claims and JSON formatting inconsistencies still remained, showing that prompt engineering can greatly improve reliability but does not completely eliminate model variability.
